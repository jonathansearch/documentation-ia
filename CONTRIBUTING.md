# Guide de contribution

Merci de votre intérêt pour améliorer cette documentation ! 🙏

---

## 🎯 Types de contributions bienvenues

- ✏️ **Corrections** — fautes d'orthographe, erreurs factuelles, liens cassés
- ➕ **Ajouts** — nouveaux chapitres, exemples, schémas, définitions
- 🔄 **Mises à jour** — le domaine de l'IA évolue vite, la documentation doit suivre
- 🌍 **Traductions** — versions dans d'autres langues

---

## 📋 Règles de rédaction

1. **Langue** : le français est la langue principale de ce projet
2. **Ton** : pédagogique, clair et accessible aux débutants
3. **Format** : Markdown, avec titres hiérarchisés et tableaux quand pertinent
4. **Structure** : chaque chapitre commence par un titre et un lien de retour au sommaire, et se termine par des liens de navigation
5. **Exactitude** : vérifiez vos informations ; évitez les affirmations non sourcées

---

## 🔀 Processus de contribution

```bash
# 1. Forkez le dépôt, puis clonez votre fork
git clone https://github.com/votre-nom/documentation-ia.git
cd documentation-ia

# 2. Créez une branche descriptive
git checkout -b amelioration/chapitre-5-exemples

# 3. Faites vos modifications, puis committez
git add .
git commit -m "Ajout d'exemples au chapitre 5"

# 4. Poussez et ouvrez une Pull Request
git push origin amelioration/chapitre-5-exemples
```

---

## ✅ Avant de soumettre

- [ ] Le texte est relu (orthographe et grammaire)
- [ ] Les liens internes fonctionnent
- [ ] La structure du document est respectée
- [ ] Le table des matières du README est mis à jour si nécessaire
