## 10.2 📚 Livres recommandés

### Pour tous
- **« Intelligence artificielle : la grande explication »** — Thierry Poibeau
- **« IA : la plus grande mutation de l'histoire »** — Kai-Fu Lee
- **« Superintelligence »** — Nick Bostrom (réflexion philosophique)

### Pour praticiens
- **« Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow »** — Aurélien Géron *(disponible en français)*
- **« Deep Learning »** — Ian Goodfellow, Yoshua Bengio, Aaron Courville (la référence technique)

## 10.3 🛠️ Outils pour pratiquer

| Outil | Usage |
|---|---|
| **Python** | Le langage de référence de l'IA |
| **Jupyter Notebook / Google Colab** | Coder et expérimenter dans le navigateur (gratuit) |
| **scikit-learn** | Machine Learning classique, idéal pour débuter |
| **TensorFlow / PyTorch** | Frameworks de Deep Learning professionnels |
| **Hugging Face** | La plus grande plateforme de modèles open source |
| **Kaggle** | Compétitions de data science et datasets gratuits |

## 10.4 🤖 Essayer l'IA générative dès maintenant

- **ChatGPT**, **Claude**, **Gemini** — assistants conversationnels

## 10.5 🌍 Communautés et veille

- **Hugging Face** et **arXiv** — les publications de recherche
- **Communautés locales** — hackathons, meetups tech et clubs IA dans les universités (l'écosystème tech camerounais et africain est très actif !)
- **Podcasts et newsletters IA** — pour suivre l'actualité sans se noyer

---

## 10.6 🗺️ Parcours suggéré

```
1. Comprendre      →  Cette documentation + Elements of AI
2. Coder           →  Python + Google Colab
3. Pratiquer       →  scikit-learn sur des datasets Kaggle
4. Approfondir     →  Deep Learning (fast.ai ou Andrew Ng)
5. Contribuer      →  Projets open source, hackathons
```

> 💡 **Conseil** : la pratique prime sur la théorie. Dès que possible, codez un petit projet — même modeste — c'est ainsi qu'on apprend vraiment.
